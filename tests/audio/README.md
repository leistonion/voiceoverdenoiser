# Test Audio Set (Placeholders)

Place the following WAV files here for QA:

1. `voice_ac_hum.wav` - close-mic voice with low-frequency AC hum.
2. `voice_hiss.wav` - voice with broadband hiss/static.
3. `voice_room_reverb.wav` - same script in a reflective room.
4. `voice_clean_reference.wav` - studio-clean baseline take.

Recommended capture format: mono, 48 kHz, 24-bit PCM.

Use `abCompare=Dry Reference` in the plugin to perform rapid A/B checks in REAPER.
